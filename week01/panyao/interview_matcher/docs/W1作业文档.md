## 三、环境搭建

- 工程用 **uv** 管理（`uv init` 建立）：`pyproject.toml` 声明依赖与控制台脚本，`uv.lock` 锁定版本，`.python-version` 指定 Python 3.12
- 初始化：`uv sync` 自动创建 `.venv`、装好依赖，并把 `w1-*` 命令注册到 `.venv\Scripts`
- 加依赖：`uv add <包名>`，自动写入 `pyproject.toml` 并同步环境
- 代码结构：标准 src 布局，`src/interview_matcher/` 为唯一代码根，各周模块按 `weekN` 分目录，共用 `common/`

踩坑记录：直接敲系统里的 `python` 时，解释器会指向不同运行时，出现 `ModuleNotFoundError: No module named 'openai'`。
解决办法是**统一用 `uv run` 启动**（或 `run.ps1` 封装），保证每次都跑在项目自己的 `.venv` 里，不再依赖全局环境。

## 七、技术亮点

- **统一客户端 + 环境变量注入**：换模型、换供应商零改代码，W3–W8 全部复用这一层。
- **工具是业务工具**：面试官池查询在 W5 演进为 RAG 检索节点，轮次规则在 W6 演进为流程规划节点。
- **循环里已预演 Agent Loop**：`tool_calls` → 本地执行 → 结果回传 → 无工具调用才输出，并设 5 轮上限防死循环；W4 会补齐参数校验、超时与降级。
- **工程结构按可交付标准组织**：标准 src 布局 + console script 入口，换机器 `uv sync` 一条命令就能还原环境并恢复全部命令。
